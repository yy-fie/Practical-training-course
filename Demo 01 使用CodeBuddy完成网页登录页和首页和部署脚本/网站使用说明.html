网站使用说明

一、环境准备

  1. 安装 Python 3.9+（本机已具备）；
  2. 启动后端接口服务（Demo 02 FastAPI 项目 api1 目录）： 双击「启动FastAPI接口项目.bat」，确认输出 接口文档：http://127.0.0.1:9001/docs；
  3. 启动本站：双击「一键启动脚本.bat」，浏览器自动打开登录页 http://127.0.0.1:8000/login.html。

二、登录流程

  1. 输入 UsersInfo 表中已存在的手机号（或邮箱）与密码；
  2. 输入右侧验证码（看不清可点击图片或“换一张”）；
  3. 点击「登录」，前端调用 POST http://127.0.0.1:9001/api/users/login 完成验证；
  4. 验证成功后将用户信息写入 Session（sessionStorage），并跳转到首页；
  5. 首页左下角显示当前登录用户的真实姓名（来自 UsersInfo.realName）；
  6. 验证失败时页面提示“用户名或密码错误”，可重新输入。

三、首页操作

  1. 左侧导航可切换到「按站点分析」「按月份分析」两个页面（右侧 iframe 展示）；
  2. 左下角用户卡片显示真实姓名与手机号，点击「退出」清除 Session 并回到登录页。
